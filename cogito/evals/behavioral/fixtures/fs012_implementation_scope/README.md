# Login input module

Requires Node.js 24 or newer. No package installation is needed.

- `src/login.ts`: prepares input for a separate authentication client.
- `tests/login.test.mjs`: targeted input preparation tests.
- `src/banner.ts`: independent heading copy; the current title has a visible "Sing in" typo.
- `notes/operations.txt`: office inventory notes, unrelated to the application.

Product requirements live in `docs/project/product-requirements.md`; the active Slice is in the Blueprint.
